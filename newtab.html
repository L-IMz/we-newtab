在线壁纸源 0

从第三方壁纸站搜索并直接在标签页里播放（图片 / 动态 / 视频）。 场景壁纸（scene.pkg）只有 WE 工坊提供，第三方站点没有该格式。

如何添加壁纸站接口

填 4 个东西：接口地址、列表路径、字段映射。地址里可用占位符 {q} 关键词、{page} 页码、{key} 密钥。

  1. Wallhaven（图片，可免密钥）：地址 https://wallhaven.cc/api/v1/search?q={q}&page={page}，列表 data， 预览 thumbs.small，文件 path
  2. Giphy（动态图，需密钥）：地址 https://api.giphy.com/v1/gifs/search?api_key={key}&q={q}&limit=24， 列表 data，预览 images.fixed_width.url，文件 images.original.url
  3. Pexels（视频/图片，需密钥）：地址 https://api.pexels.com/videos/search?query={q}&per_page=24，请求头 Authorization，列表 videos，预览 image， 文件 video_files.0.link
  4. Pixabay（图片，需密钥）：地址 https://pixabay.com/api/?key={key}&q={q}&per_page=24，列表 hits，预览 webformatURL，文件 largeImageURL

其它站点：按同样格式填写即可，字段用点号路径，数组用数字下标 （如 results.0.thumb）。
