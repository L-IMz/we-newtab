# WE 壁纸新标签页 1.0.0

首个正式版。相比 `1.0.0-alpha`，这一版把属性面板真正修好，并删掉了自定义组件页。

## 新增

- **从壁纸取色（莫奈）**：场景壁纸读自身的 `schemecolor`，视频取当前帧、图片取画面主色，生成界面强调色 `--accent` / `--accent-dim` / `--accent-ink`；浅色强调色自动配深色文字，灰度画面回退默认蓝。设置面板「壁纸选项」里可开关，默认开启。
- **分组属性（group）**：支持 WE 的 `group` 类型，渲染为分组标题；`cond=分组名` 这类条件按“始终成立”求值，组内子项不再被误隐藏。
- 每个属性行带 `data-prop` 标记，便于定位与自动化测试。

## 修改

- **属性下发改用 `declareUserProperties`**：一次调用同时更新 `liveUserProps`、图层绑定（visible/color/alpha/scale 等）、重算可见性，再通知壁纸脚本。此前用的 `setProperties` 只把值转发给脚本，靠属性条件控制显隐的图层完全不跟手。
- **滑块外观重做**：轨道 4px、按当前值用强调色填充（`--pct`）、14px 圆形滑块头带描边、聚焦时强调色光晕。
- **数值列重做**：固定 46px 宽、右对齐、等宽数字、超长省略；整数属性显示 `0` / `-20`，小数属性按 `precision` 补零显示 `0.60` / `1.00`。
- 设置面板简化为单页（壁纸），移除选项卡结构。
- 强调色文字（主按钮、选中的开关滑块）跟随主题，不再写死深蓝。

## 修复

- **拖动滑块数值变 NaN**：回调闭包捕获的 `control` 变量随后被重新赋值为容器 `div`，读到 `control.value === undefined`，导致右侧数字变成空白、`--pct` 变成 `NaN%`、引擎收到 `NaN` 等于没改。改为局部 `slider` 引用。
- **修改不生效 / 改完对应模块消失**：属性下发 API 用错，叠加 `group` 条件求值为 `false` 把整组子项隐藏。
- **滑块右侧数字不显示**：flex 布局下轨道把数字列挤出可视区，改成 `grid: 1fr 46px`。
- **属性标签折成两三行**：`.prop-label` 继承了全局 `label` 的栅格布局，改为块级。
- **滑块周围的白色框**：通用 `input:hover` / `input:focus` 样式漏到了 `range` 上，现已排除并复位边框与底色。

## 删除

- **自定义页（组件页）整个功能**：`board.js`、12 列网格、时钟/搜索/便签/倒计时/天气/图标组件、拖拽吸附、取色调用，以及对应的 DOM、CSS、存储键与启动逻辑。
- 文档与展示页里的自定义页章节、`docs/img/board.png` 截图。

## 验证

- 52 张场景壁纸逐张挂载并修改属性：无报错、无状态失败、场景持续出帧。
- 《樱花庄的宠物女孩》：183 个属性行，86 滑块 / 31 开关 / 22 下拉 / 5 文本 / 26 颜色，共 398 次检查，0 报错、0 UI 异常。
- 离线用例 23/23 通过。
